DESCRIÇÃO DA ATIVIDADE.

Criar um CRUD funcional utilizando a estrutura atual do projeto.
- Criar produto.
- Listar produtos.
- Excluir produto da lista clicando em excluir ou ícone de lixeira.

## Executar

1. Instale as dependências: `pip install -r requirements.txt`
2. Inicie o servidor: `python app.py`
3. Acesse `http://127.0.0.1:5000`

O banco SQLite `produtos.db` e a tabela de produtos são criados automaticamente na primeira execução.
